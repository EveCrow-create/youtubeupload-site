プライバシーポリシー

最終更新日: 2026年11月9日

1. このアプリについて

YouTubeUpload は、開発者本人が自分の YouTube チャンネルに動画と字幕を投稿するための個人用ツールです。アプリの説明もご覧ください。

2. 取得する情報

このアプリは、開発者本人の Google アカウントで認可を受け、次の2つの権限を使います。

  • YouTube への動画のアップロード(https://www.googleapis.com/auth/youtube.upload)
  • YouTube への字幕の登録(https://www.googleapis.com/auth/youtube.force-ssl)

認可の結果として得る更新トークンは、開発者本人のパソコン内のファイルにだけ保存します。ほかの人のアカウントの情報は取得しません。

3. 情報の使い方と共有

取得した権限は、動画と字幕を開発者本人のチャンネルに投稿するためだけに使います。情報を第三者に提供、販売、共有することはありません。広告にも使いません。

4. Google API サービスのユーザーデータに関するポリシーへの準拠

YouTubeUpload による、Google API から受け取った情報の使用と、ほかのアプリへの転送は、Google API サービスのユーザーデータに関するポリシー(限定使用の要件を含む)に準拠します。

5. 権限の取り消し

開発者は、Google アカウントの「サードパーティのアクセス」から、いつでもこのアプリの権限を取り消せます。

Privacy Policy

Last updated: November 9, 2026.

YouTubeUpload is a personal tool for its developer to upload videos and captions to the developer's own YouTube channel. It uses the youtube.upload and youtube.force-ssl scopes with the developer's own Google account only. The refresh token is stored only in a file on the developer's own computer. No data is collected from other people, and no data is shared with, sold to, or transferred to third parties.

YouTubeUpload's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Access can be revoked at any time at myaccount.google.com/permissions.
